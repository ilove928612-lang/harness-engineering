# Style Brief — 缰绳档案页

- 目标与受众：一张能单独转发（社交媒体 / README 引用）的项目海报；读者第一眼记住「驭缰工程」与"人类掌舵，智能体执行"，停留 30 秒能带走范式转变 + 六概念 + 实证刻度 + 仓库地址。
- 输出场景与画布：竖版 3:4（720×960），适配移动端浏览与打印张贴；直接按竖版构图，不从 16:9 拉伸。
- 一句话核心信息：工程师的产出从代码变成了约束系统——这座档案记录了从概念到实践的完整驯服过程。
- 视觉概念/隐喻：**一页「驭缰档案」**——暖纸底像档案纸，一条缰绳曲线从巨字标题甩出，编号段落像档案条目自上而下码放，末端收进深色档案脚。
- 主视觉焦点：92px 得意黑巨字「驭缰工程」+ 从字间甩向右上的缰绳曲线（起点墨色锚点 = 人类，终点箭头 = 智能体）。
- 海报级视觉动作（为何不是普通内容页）：标题与缰绳曲线互相穿插构成图形本身；全页只有一条主线、一个强调色，缩略图下仍能认出"巨字 + 一条飞线"。
- 视觉 DNA：暖纸底 `#F5F1E8` × 深墨 `#1F1C17` × 缰绳橙红 `#C2481D`（唯一强调色，只给关键路径与编号）；几何黑体标题 + 人文黑体正文；信息以编号 + 细线分段，不用圆角卡片。
- 主视觉媒介与备选比较：比较过（a）拿 OpenAI 文章截图 / 仓库截图做主图——像技术报告且有版权与像素质量问题；（b）六概念画成环形图占主区——在竖版里挤压数据带；最终选（c）纯排印 + 矢量缰绳曲线：主题本身是"约束/缰绳"这种抽象关系，排印 + 线条最诚实也最可编辑。
- 阅读顺序与构图：巨字标题（锚定）→ 01 范式一行流（人类→约束系统→智能体→代码→机器）→ 02 六概念双列条目 → 03 数据刻度带 → 04 学习闭环一行 → 深色档案脚（仓库地址）。单栏纵向流，编号在左缘对齐成轴。
- 配色角色：纸底=档案纸；深墨=正文与结构；橙红=缰绳、编号、闸门等"人类掌控"语义；暖灰=注释。
- 中英文字体与层级：标题 得意黑（92/17/13.5），正文 MiSans（13/11.5/10.5），拉丁与数字 Liter；三个字号台阶以内。
- 图片选择与处理：不用照片素材——避免为"有素材"而塞图；全部为可编辑矢量与文字。
- 图形/图表语言：细线（1px hairline）分段；流程用 stealth 箭头；数据带用数黑体大数字，不用图表框。
- 信息密度与留白：五段条目密度均衡，标题区与数据带前后留白最大；正文最小字号 10.5px，竖版近距离阅读可辨。
- 需要避开的套路：圆角卡片墙、蓝紫渐变、荧光霓虹、假档案编号/印章、图标矩阵凑数；最可能退化成"普通技术报告封面"——检查时确认曲线确实穿过标题区、深色档案脚确实压住底边。
- 未选方向及原因：照片主视觉（无真实可用素材，易变商业感）；环形信息图主视觉（竖版空间利用差，字号会被迫缩小）。
